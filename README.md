# Template for gitignore

A `.gitignore` for the files an operating system leaves behind in any directory it touches: Finder metadata and resource forks on macOS, `Thumbs.db` and its relatives on Windows, and the rest of the noise that has nothing to do with the project. Start a repository from it and add the project's own entries below.

```bash
curl -fsSL https://raw.githubusercontent.com/heyvaldemar/gitignore-template/main/.gitignore -o .gitignore
```
